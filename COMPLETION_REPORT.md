## 🎯 Customization Examples

### Update Hotel Contact
Edit `public/data/hotel.json`:
```json
{
  "contact": {
    "phone": "+91 YOUR_PHONE",
    "email": "your@email.com",
    "whatsapp": "+91 YOUR_WHATSAPP"
  }
}
```

### Add New Room
Edit `public/data/rooms.json` and add to the array.

### Change Primary Color
Edit `tailwind.config.js`:
```javascript
gold: '#your-color-code'
```

### Add More Attractions
Edit `public/data/attractions.json` - automatically gets a page!

### Replace Images
Place your images in:
- `public/images/` - Hotel images
- `public/attractions/` - Attraction images
- `public/gallery/` - Gallery images

## 📞 Support & Troubleshooting

### Issue: npm not found
**Solution**: Install Node.js from nodejs.org and restart computer

### Issue: Port 3000 in use
**Solution**: `npm run dev -- -p 3001`

### Issue: Module errors
**Solution**: `npm cache clean --force && npm install`

### Issue: CSS not loading
**Solution**: Rebuild Tailwind with `npm run build`

See **SETUP.md** for more troubleshooting tips.
